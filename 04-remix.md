# Remix It (Rung 2)

This is the heart of the whole workshop.

A reskin changes how a game *looks*. A remix changes what it *means* — by finding the **expectation** the game relies on, and breaking it. It's the difference between repainting a house and changing what the house is *for*.

And here's the secret: a great remix usually breaks **just one expectation.** Not ten. One.

## The proof: how Half of Me was made

**Memory of Home** is a matching game. Normally, memory games ask you to find two *identical* cards. Its designer changed one rule:

> Two cards match if they share the same object **OR** the same colour — never both.

That's it. That one rule means every memory you recover is incomplete. From that single change came **Half of Me** — a game about losing your home and keeping only half of it. New title, new story, new feeling — all hanging off *one changed rule*.

That's your target today.

## Step 1 — Find the expectation the game relies on

Every game trains you to expect something without saying so: a match earns points, a locked door needs a key, more is better. Look back at the game you reskinned and find the expectation it leans on hardest. In the **[catalogue](02-pick-a-game.md)**, each game has a line called *"the mechanic that carries it."* That's your raw material. Ask the AI to be sure:

> *In one sentence each, list the main rules of this game — how you score, how you win, how you lose, what the player does over and over.*

Now read that list and ask the designer's question:

> **"What is this game training me to expect — and what would it mean if that expectation broke?"**

## Step 2 — Pick ONE rule to bend

Some of the most powerful moves are simple inversions or twists:

| Original rule | Bend it to… | New meaning |
|---|---|---|
| Matching earns points | Matching *costs* you something | Restraint, sacrifice, loss |
| You can move freely | You can only go forward | Regret, irreversibility |
| Win by finishing first | Win by helping someone else finish | Care over competition |
| Match identical cards | Match on one quality, never both | Incompleteness, memory |
| More is better | Too much kills you | Moderation (this is Pill Match!) |

Write your bend as one sentence: *"Instead of [old rule], now [new rule], which makes the game about [meaning]."*

## Step 3 — Ask the AI for it

Be specific about the rule, and tell it the *why* — the AI makes better choices when it knows the meaning you're after. (More phrasings in the **[remix prompt library](prompts/remix-prompts.md)**.)

> *I want to change one rule. Right now, [describe the current rule]. I want it to instead [describe the new rule]. The reason is that I want the game to feel like [your meaning]. Please make that change and keep everything else working.*

Then **Run** it and *play it.* This is the moment of truth — does the new rule actually create the feeling? Sometimes it does instantly. Sometimes it needs a nudge:

> *That works, but it's too easy / too punishing / too fast. Adjust it so the player really feels [the meaning].*

## Step 4 — Let the story catch up to the rule

Once the rule feels right, the words and look should follow it (back to Rung 1 skills):

> *Now that the rule has changed, rewrite the title, intro and ending so the whole game is clearly about [your meaning].*

## A word of encouragement

Your first remix might miss. The rule you change might not create the feeling you hoped. **That's the workshop working, not failing** — it means you're now thinking like a designer, testing whether a rule says what you meant. Change it again. Try a different rule. This is the actual craft, and you're doing it.

When the rule and the feeling finally click — that little jolt of *"oh, it really feels like that now"* — that's the thing we came here for.
