# Remix Prompts (Rung 2)

Change *one rule*, change the meaning. This is the powerful stuff. Copy, fill in the `[brackets]`, paste into the AI.

## Find the rule worth changing

> In one sentence each, list the main rules of this game: how I score, how I win, how I lose, and what I do over and over.

> Which single rule, if I changed it, would most change what this game feels like it's *about*?

## Make the change (the core move)

The pattern that works: **say the old rule, the new rule, and the meaning.**

> I want to change one rule. Right now, [describe the current rule]. I want it to instead [describe the new rule]. The reason is I want the game to feel like it's about [your meaning]. Please make that change and keep everything else working.

## Ready-made bends to borrow

> Make matching *cost* the player something instead of earning points, so the game becomes about restraint and loss.

> Make it so the player can only move forward, never back — I want it to feel like regret.

> Change winning: instead of finishing first, the player wins by helping another character finish. The game should feel like care matters more than competition.

> Make "more" dangerous — doing the action too many times should cause a loss, so the game is about moderation.

> Make a match work only when two things share [one quality] but not [another], so every success feels incomplete.

## Tune the feeling

> That works, but it feels too [easy / punishing / fast / slow]. Adjust it so the player really *feels* [your meaning].

> Right now the change is invisible to the player. Make it clearer that [the new rule] is happening, without adding instructions.

> Add a small moment of [hesitation / consequence / reward] when the player [does the key action], to make the meaning land.

## Let the story catch up to the rule

> Now that the rule has changed, rewrite the title, intro, and ending so the whole game is clearly about [your meaning].

> Suggest three possible titles for the game now that it's about [your meaning].

## If it didn't work (this is normal!)

> That rule change didn't create the feeling I wanted. Let's undo it and try changing [a different rule] instead.

> Explain in simple terms why that change made the game feel [the wrong way], so I can pick a better rule.
