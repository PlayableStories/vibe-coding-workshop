# Reskin Prompts (Rung 1)

Change the words and the look. Keep the rules. Copy, fill in the `[brackets]`, paste into the AI.

## Understand what you've got

> Give me a plain-English summary of what this game is and how it plays. I'm not a coder — keep it simple.

> Where does the text the player reads live? I want to change the words, not the rules.

## Re-theme the whole game

> I want to re-theme this game. Instead of [original theme], it's now about [your new theme]. Rewrite all the text the player sees — the title, instructions, story fragments, and endings — to fit. Keep the rules exactly the same.

> Rewrite the opening screen so it sets a [warm / tense / playful / sombre] mood and hints that the game is about [your theme].

> Write a closing line for the ending that leaves the player feeling [the one feeling from your worksheet].

## Change the words in detail

> Rename [the four meters / the ranks / the objects / the cards] to: [your list].

> Rewrite the dilemmas / prompts so they're about [your situation]. Keep the same number of them and the same structure.

> Make the tone of all the writing more [funny / serious / poetic / dry and satirical].

## Change the look (describe the *feeling*, not exact colours)

> Change the colour palette so the game feels [warm and nostalgic / cold and corporate / dreamlike / urgent]. Keep everything readable.

> Make it look more [hand-drawn / clean and minimal / retro / soft and faded].

> The mood should be like [a faded photograph / a fluorescent-lit office / a child's storybook / a late-night city]. Adjust the colours and fonts to match.

## Personal touches

> Change the title at the top to "[Your Title]".

> Add my name as the creator somewhere tasteful, like the start or end screen: [your name].

## After every change

> Run it. *(then look at the preview and play it)*

> I like that — keep it. Now let's change [the next thing].

> Double-check nothing still accidentally mentions the original [CEO / pills / home / racing] theme.
